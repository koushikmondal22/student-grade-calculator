# Student Grade Calculator 🎓

A beginner-friendly Python project that calculates a student's total marks, percentage, grade, and pass/fail result.

## 📌 Features

- Takes marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Shows Pass/Fail result
- Validates marks between 0 and 100
- Handles invalid text input

## 📚 Subjects

The program accepts marks for:

- Mathematics
- Python
- English
- Computer Science
- Statistics

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

Run the program using:

```bash
python grade_calculator.py
